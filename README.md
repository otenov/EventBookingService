# EventBookingService

REST API для управления мероприятиями на ASP.NET Core.
Сервис позволяет создавать, получать, обновлять и удалять мероприятия.
Данные хранятся в памяти приложения. 

## Возможности
- получение списка всех мероприятий;
- получение мероприятия по идентификатору;
- создание мероприятия;
- обновление мероприятия по идентификатору;
- удаление мероприятия по идентификатору;
- валидация входных данных.

## Технологии
Проект использует следующие технологии:
- C#
- .NET 10
- ASP.NET Core Web API
- Swagger / OpenAPI


## Запуск проекта

1. Клонировать репозиторий:

```bash
git clone https://github.com/otenov/EventBookingService.git
```

2. Перейти в папку проекта:

```bash
cd EventBookingService
```

3. Восстановить зависимости:

```bash
dotnet restore
```

4. Собрать проект:

```bash
dotnet build
```

5. Запустить проект:

```bash
dotnet run
```

## API

1. `GET /api/events`  
   Получить список всех мероприятий.  
   Ответ: `200 OK`.

2. `GET /api/events/{id}`  
   Получить мероприятие по идентификатору.  
   Ответы: `200 OK`, `404 Not Found`.

3. `POST /api/events`  
   Создать новое мероприятие.  
   Ответы: `201 Created`, `400 Bad Request`.

4. `PUT /api/events/{id}`  
   Полностью обновить мероприятие по идентификатору.  
   Ответы: `200 OK`, `400 Bad Request`, `404 Not Found`.

5. `DELETE /api/events/{id}`  
   Удалить мероприятие по идентификатору.  
   Ответы: `204 No Content`, `404 Not Found`.

## Валидация
- `Title` обязателен и не должен превышать 50 символов;
- `StartAt` обязателен и должен находиться в диапазоне от `01.01.2000` до `01.01.3000`;
- `EndAt` обязателен и должен находиться в диапазоне от `01.01.2000` до `01.01.3000`;
- `EndAt` должен быть позже `StartAt`.
